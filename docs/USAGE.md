## 1. 五分钟开一本新书

### 你只需要说

```
帮我开一本新书，都市异能，主角能听见物品的记忆，目标 200 万字
```

Agent 会问清 4 件事（书名、题材、一句话故事、目标规模），然后建好骨架。

### 接下来它带你走三步

| 步骤 | 产出 | 为什么重要 |
|---|---|---|
| **设定集** | 世界观 / 力量体系 / 主角卡 / 金手指 | 力量体系里写清「不能做什么」，能防住后期战力通胀 |
| **总纲** | 三幕结构 + 核心冲突 + 三条线 | 长篇的方向盘 |
| **第一卷卷纲** | 本卷目标 + 节拍表 + 伏笔计划 | 从「有个想法」到「可以写第一章」 |

> 💡 **偷懒技巧**：说「你帮我拟，我来改」就行。Agent 会给出草稿，你在上面改比从零写快得多。

## 2. 每天怎么写一章

### 你只需要说

```
写第 12 章
```

### Agent 背后做的事（你不用管，但知道会更有底）

```
1. 取写作任务书 ← 这一步是「不忘设定」的关键
   ├─ 本章章纲（大纲即法律）
   ├─ 前情提要（上一章讲了什么、结尾在哪）
   ├─ 主角当前状态（境界 / 位置 / 伤势 ← 断手就不能双手握剑）
   ├─ 未回收伏笔（哪些该收了）
   ├─ 节奏提示（感情线是不是断太久了）
   └─ 你沉淀过的写作经验
2. 写正文
3. 保存
4. 自审（抓状态冲突、章末缺钩子等）
5. 提交（把这一章的事实变化落库）
6. 汇报进度
```

### 没有章纲会怎样

Agent **会停下来**，先让你定章纲。这是故意的——

> 没有章纲就写，等于让 AI 自由发挥，几十章后必然崩。

如果你确实想自由发挥，直接说「这章我自己定，你直接写」，Agent 会照做。

### 一次写多章

```
连写 3 章
```

Agent 会逐章走完整流程（每章都提交），而不是攒着一起提交——攒着容易忘。

## 3. 想不起来的时候怎么查

直接问，用大白话：

| 你这么问 | 它怎么答 |
|---|---|
| 「主角现在什么境界？」 | 境界 + 位置 + 身体状态 + 金手指 |
| 「苏晚是谁？」 | 角色卡：身份、境界、最后出场章节 |
| 「玉佩那条伏笔收了没？」 | 伏笔台账，含「已到期未回收」告警 |
| 「哪一章写过地图？」 | 在正文/大纲/设定/摘要里全文检索 |
| 「现在写到哪了？」 | 进度 + **按优先级排序的待办清单** |
| 「节奏怎么样？」 | 三线占比 + 断档告警 |

> 💡 最省事的入口：**「写到哪了」**——它会告诉你进度、主角状态、下一章，以及「有什么没做完」。

### 想让 Agent 直接读某一项原文

平时用大白话问就够了（上一张表）。要它把原文原样调出来，就在话里带上这一项的名字——
比如「把今天的手记原文贴给我」「把第 12 章正文调出来」。Agent 会转成 `webnovel_outline action=read`，
其中 `scope` 必须显式指定，取值只有五个：

| scope | 读什么 | 搭配参数 |
|---|---|---|
| `master` | 总纲 | — |
| `volume` | 第 N 卷卷纲 | `volume=N` |
| `chapter` | 第 N 章章纲 | `chapter=N` |
| `text` | 第 N 章正文 | `chapter=N` |
| `note` | 某天的手记 | `date=YYYY-MM-DD`，缺省今天 |

**不指定 scope 会默认读总纲**——这是最常见的"读不回手记"原因：调用发出去了、也返回了内容，
但返回的是总纲，不是你要的那一项。

## 4. 编辑说有问题怎么办

### 场景：编辑说「感情线太少了」

```
你：查一下节奏
```

Agent 会告诉你：

```
🔴 感情线已连续 14 章未出现（红线 10 章）——建议安排相关情节
三线占比：主线 78% / 感情线 6% / 世界观 16%
```

**它不只告诉你问题，还告诉你怎么补**。

### 场景：怕这章崩设定

```
你：审一下第 12 章
```

六个维度检查：

| 维度 | 抓什么 |
|---|---|
| 设定一致性 | 断手还握剑、境界回退、已死角色出场、3.6⑧ 台词归属（他登记为「不知道」的事从他嘴里说出＝🔴；别人的秘密被非主人说出＝🟡） |
| 叙事连贯 | 与上一章的结尾 / 钩子接不上 |
| 节奏 | 三线断档 |
| 大纲符合度 | 章纲里的要素没写出来 |
| 伏笔 | 到期没回收、埋了没登记 |
| 追读力 | 章末没钩子、段落太长、全是叙述没对话 |

每条问题都带**原文证据**和**具体改法**，不是泛泛而谈。

## 5. 让 Agent 越写越懂你

写作过程中你会有很多「以后都这样写」的判断。**说一句就行**：

```
记住：打斗场面用短句，别用长定语，单段不超过 5 行
```

Agent 会把它存成长期记忆，**之后每一章的写作任务书里都会自动带上**。

### 什么值得记

| 类型 | 例子 |
|---|---|
| 文风 | 「主角说话不用书面语，句尾常带『吧』『嘛』」 |
| 写法 | 「动作场面用 8-15 字短句」 |
| 设定约定 | 「本书里丹药不能瞬间回满血，只能加速恢复」 |
| 读者反馈 | 「读者说前三章太慢，以后开头要直接进冲突」 |
| 人物把握 | 「林越不会主动示弱，即使吃亏也要嘴硬」 |

> ⚠️ 别记「要写得更好」这种——不可执行的记忆没有价值。

## 6. 你的文件长什么样

```
我的小说-长夜行/
├── 设定集/
│   ├── 世界观.md
│   ├── 力量体系.md
│   ├── 主角卡.md
│   └── 金手指.md
├── 大纲/
│   ├── 总纲.md
│   ├── 卷纲/第1卷.md
│   └── 章纲/第0001章.md
├── 正文/
│   └── 第0001章-夜航.md
└── .webnovel/          ← 机器维护，你不用改
    ├── state.json       进度 / 主角状态 / 三线 / 时间线
    ├── index.json       章节索引
    ├── foreshadowing.json  伏笔台账
    ├── memory.json      写作经验
    ├── commits/         每章提交记录（只增不改，可审计）
    └── summaries/       每章摘要
```

### 三个你可以放心的点

1. **全是纯文本**。你可以用任何编辑器改，可以用 git 管，可以随时打包带走。
2. **`.webnovel/` 是投影**。真源永远是 `正文/` + `大纲/`。删了它也能从正文重建。
3. **不会被静默覆盖**。已存在的文件，初始化不会覆盖；提交记录只增不改。

## 7. 常见问题

**Q：项目要放在哪？**
A：书库里任意一个子目录（bookId 就是目录名）。书库位置由部署时的 `WEBNOVEL_ROOT` 决定。

**Q：能同时写多本书吗？**
A：可以。说「切到《书名》」即可——用 webnovel_books 看有哪些书，之后每次调用带 `bookId`。

**Q：`.webnovel/` 里的文件被我不小心删了怎么办？**
A：不影响正文。重新跑一次 `webnovel_commit` 即可重建（历史章节需要逐章补，或用 git 恢复）。

**Q：能导入我已经写了一半的书吗？**
A：可以。让 Agent 建项目，然后把已有的正文放进 `正文/`（文件名用 `第0001章-标题.md` 格式），
再逐章提交。也可以只提交最近几章，之前的不补。

**Q：会不会自己改我的大纲？**
A：不会。Agent 只会**建议**，改动都要你确认。设定集和大纲是你的作品。

**Q：状态注入会不会很费 token？**
A：默认上限 1200 字符，且只在项目已初始化时注入。嫌烦可以在配置里关掉 `autoPrompt`。

**Q：我改了设定集，需要同步什么吗？**
A：不需要。设定集是真源，Agent 每次都会重新读。只有**事实性状态**（境界、位置、伏笔）才需要走提交链。

## 附录：工具与技能的对应关系

| 你想做的事 | Agent 会用的工具 | 对应技能 |
|---|---|---|
| 开新书 | `webnovel_init` | `webnovel-init` |
| 定大纲 / 章纲 | `webnovel_outline` | `webnovel-plan` |
| 写一章 | `webnovel_context` + `webnovel_commit` | `webnovel-write` |
| 审一章 | `webnovel_review` | `webnovel-review` |
| 查东西 | `webnovel_query` | `webnovel-query` |
| 记经验 | `webnovel_memory` | `webnovel-learn` |
| 看进度 | `webnovel_status` | — |
| 这本书该分几部 / 多少卷 | `webnovel_status`（`structure=full`） | — |
| 看节奏 | `webnovel_pacing` | — |
| 体检 / 修复账目 | `webnovel_doctor` | — |

技能是「操作手册」，工具是「手」。你只管说人话，Agent 自己挑。
