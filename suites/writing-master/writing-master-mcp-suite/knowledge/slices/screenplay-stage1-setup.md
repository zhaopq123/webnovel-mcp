# 阶段1：核心设定与人物（logline → 三维人物 → 体量换算）

## 1. 一句话故事（logline）

格式：**主角身份 + 想要什么 + 最大的障碍 + 赌注（输了失去什么）**，35字以内。写不出 35 字内的 logline = 故事核还没想清楚，禁止进入下一步。一句话禁用形容词堆砌，只允许具体名词与动词。

## 2. 主题论断

一句话写清"本剧相信什么"（例：只有放下对完美的执念，才能留住真正的人）。主题只能通过人物选择呈现，**任何角色不得在台词中直说主题**（说教禁令）。主角弧光的终点=主题论断的具象化。

## 3. 主角建模（复用19节6.1/6.2三维建模，适配）

- **三维档案**：外在标签2-3个（可视化的：穿着/习惯动作/随身物）｜欲望与恐惧（各一句，必须互相冲突）｜秘密与创伤（至少一项在季/部中段才揭示）｜内在矛盾一组（想要A却必须做B）。
- **动机三段演进**（复用19节10.3）：开局动机（表面想要）→ 中点颠覆（动机被真相击碎）→ 终局动机（真实需要）。三段写入档案，后续每集标定主角当前段位。
- **人味铁律**（复用19节6.13）：三个小毛病 + 一个私心 + 每季至少一次"因缺点付出代价"的预设落点。禁完人。
- **视觉人味**（剧本特有）：一个可重复出现的标志性小动作/小物件（适配19节"可回环核心物件"：开篇埋入、关键集引爆）。

## 4. 关系功能位（复用19节第十二节）

为每个核心人物登记"对主角弧光的功能"：镜像（走主角拒绝的路）｜松动者（专攻主角内在矛盾）｜对手（制造外部压力）｜反映者（替观众发问）。功能位=1 的角色不得多于 1 个；无功能位的人物删除或合并。

## 5. 反派设计（复用19节洋葱层+计划线）

- 洋葱层：一季剥一层，每层揭开后必须"解释前层所有反常"（适配19节5.7串联引爆）。
- 反派计划线独立推进：主角不在场时反派也在行动，每集标注反派当前步骤与对主角的认知等级。
- 反派立体化：三维档案齐全，与主角欲望同构、手段相反。

## 6. 俗套声明制（复用19节10.2）

立项时声明 3 项"本剧不写的俗套"（写进设定表）。写作中触碰即触发返工警示。评审自检必含此三项。

## 7. 剧本体量换算（适配19节第二节）

- 单位链：场（最小单元，约1页≈1分钟）→ 序列（3-8场构成一个小目标循环）→ 集（2-4个序列）→ 部/季。
- 集数 × 每集页数 = 总页数；据此换算：每集序列数、每序列场数、单集三幕小循环数量。
- 舞台剧换算：幕（2-3幕，含中场）→ 场（scene）→ 拍数；一幕一场大戏原则，换景最小化。
- 中途改体量：重算后续参数并输出调整说明（复用19节2.1）。
