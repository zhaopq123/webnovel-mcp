# 阶段3B：术语表纪律与语言规范

## 1. 术语表纪律（对应台账 names.tsv）

1. **首次出现**：术语加粗 + 当处一句话定义 + 入术语表（主名/定义/首现章/别名）。
2. **一词一义，一义一词**：全书同一概念只用一个名（禁"又称/也叫/以下简称"漫游；确需别名的在术语表登记主名+别名，正文别名仅首现时括注一次）。
3. **定义写法**："X是【类别】，用于【做什么】"——写"是+做什么"，禁用"不是什么"绕圈定义，禁循环定义（用Y定义X、又用X定义Y）。
4. **禁止生造缩写**；外来词首现给原文对照（平台已确认的专有写法除外，须在专名表内）。
5. 缩略语规则：全书出现≥3次的概念才值得缩写；首现"全称（缩写）"，此后只用缩写。

## 2. 口径统一（全书一致性）

- 数字格式：万/亿口径、百分比小数位、日期格式——立项时定死，写入口径表（放术语表头部）。
- 单位：全书统一（禁同书混用"KB/千字节"式变体）。
- 每章交付前对照术语表与口径表全文扫描；漂移处当章修正，禁止"下章再改"。

## 3. 语言规范（复用19节15.6，适配非虚构）

- 简体中文规范书写；全角标点；禁英文混入正文（已登记专有名词除外）。
- 句子纪律：技术段落单句≤40字；连续三个以上长句必须插入短句或列表。
- 指代纪律："它/这/上述"连续指代不超过两段，之后必须重述主语（工具书读者随时跳读，禁让读者往回翻）。
- 主动语态优先；"被广泛应用于诸多领域"式空话黑名单（禁：若干/诸多/一定程度上/众所周知/毋庸讳言）。

## 4. 每章术语自检

①新术语全部首现即定义并入表；②同义漂移扫描（抽全书已用名对照表）；③缩写合规；④口径无漂移；⑤无生造词。
