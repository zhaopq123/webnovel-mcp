# 阶段4：分场大纲（场次表）

## 1. 场次表字段（每场一行，全字段必填）

| 字段 | 说明 |
|---|---|
| 场号 | 全集统一编号（S1E03-04=第1季第3集第4场） |
| 场景 | 场景名+内/外+日/夜（舞台剧：第X幕第X场+换景方式） |
| 出场人物 | 全列（含无名功能性角色标注） |
| 本场功能 | 推进哪条线（A/B/反派线/世界观）+什么功能（建置/对抗/转折/偿还钩子） |
| 核心冲突 | 一句话（无冲突的场=过渡场，全集过渡场上限2） |
| 进入钩子→离开钩子 | 场首承接什么、场末留下什么（场末必须有"势能变化"） |
| 预估页数 | 1页≈1分钟；合集页数与该集时长匹配 |
| 信息差 | 观众知道 vs 场内角色知道（标注三模式） |

## 2. 删场测试（复用19节结构纪律，硬性）

删掉本场剧情是否受损？无损=删或与同功能场合并。同功能场合并原则：两个"信息交付"场若可共享空间，合并为一个带冲突的场。

## 3. 序列检查（3-8场=一个序列）

每个序列必须有：进入时目标 → 受阻 → 转折 → 离开时新态势。序列目标模糊=整段重写。一场只做一件事（一场一义）。

## 4. 人物出场三笔（复用19节6.3，硬性）

每个具名人物首次出场三笔齐全：**一个动作选择**（观众看到他"做什么"而非"说什么"）+ **一句印记台词**（体现语言指纹）+ **一个反差**（与第一印象不符的细节）。缺任一笔=返工该场。

## 5. 场景经济性

- 大场面/特效场：标注预算级别，同类场集中编排，禁散撒。
- 换景成本（舞台剧）：换景次数最小化，场景归并（同一空间承担多场多功能）。
- 新场景引入上限：每集新场景≤全集场数的40%（超出=空间涣散警示）。

## 6. 分场自检（交付前）

①场号连续、无缺号；②每场"离开钩子"非空且与下场"进入钩子"咬合；③出场人物均在人物台账且名词与专名表一致；④过渡场≤2；⑤页数合计与集时长偏差≤10%；⑥每个序列四要素齐全；⑦重要人物首场三笔齐全。
