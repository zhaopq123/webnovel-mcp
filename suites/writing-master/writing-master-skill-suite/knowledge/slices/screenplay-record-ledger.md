# 剧本台账与一致性映射

## 1. 台账语义映射（WritingMaster 脚本台账 ↔ 剧本概念）

| 台账文件 | 剧本概念 | 维护时机 |
|---|---|---|
| names.tsv（专名表） | 人名/地名/机构/职务/术语，错字核对唯一基准 | 新名词确立即录 |
| characters.json | 人物三维档案+语言指纹+口语档位+每集状态（位置/信息量/关系级别） | 每集交付后 |
| timeline.json | 故事内时间线+场次时序（日夜连续性） | 每集交付后 |
| foreshadow.json | 伏笔/支票/可回环物件（埋设集-暗示集-引爆集） | 每集交付后 |
| suspense.json | 悬念账户四层（场/集/季/剧级，余额与预期兑付集） | 每集交付后 |
| info-gap.json | 观众/角色信息差三模式逐集状态 | 每集交付后 |
| plotlines.json | A/B线咬合点+反派计划线（当前步骤/对主角认知等级）+动机演进段位 | 每集交付后 |
| summaries/ | 每集摘要（一句话+钩子+状态变化）+每季摘要（≤15行） | 每集/每季末 |
| archive/ | 已完结季归档（历史区，引用只依据季摘要） | 季末 wm-archive |

## 2. 维护节奏

- 每集交付后立即 `wm-commit.sh` 提交本章（集）摘要与各台账增量；跳过=下集自检必报"台账无此信息"。
- 每季末 `wm-archive.sh` 归档，此后引用旧季剧情只依据季摘要（复用19节防幻觉铁律3）。
- 新会话开工前 `wm-restore.sh` 恢复上下文包；疑似台账异常先 `wm-doctor.sh` 体检。

## 3. 一致性三不

不凭空回忆（只查台账）；不无声造词（先入专名表）；不跨季引用正文细节（只引用季摘要）。
