# 阶段3A：章节模板与写作纪律

## 1. 统一章节结构（六段制，按需微调但骨架不得缺）

1. **开篇钩子**（≤200字，三选一）：场景化痛点（读者被卡住的真实瞬间）/ 反直觉观点（挑战默认做法）/ 真实案例（结果先行）。禁用"在本章中，我们将学习……"式学院开场。
2. **本章问题**：读者带着什么问题来，一句话点明（呼应章标题）。
3. **核心论点**（1-3个）：每个论点 = 论断 + 论据（数据/来源）+ 案例。
4. **操作步骤**：清单化/步骤化/模板化——**读者可直接照做的颗粒度**（"第一步：打开X，选择Y"，不是"熟悉相关功能"）。
5. **常见坑与排错**：≥3条"如果你卡在X，多半是因为Y"式条目（对应读者真实失败点）。
6. **小结+下一章钩子**（≤5行）：本章要点回顾 + 自然引出下一章问题。

## 2. 一章一义（复用19节"一场一义"）

本章只解决一个问题。写作中发现的新问题：记入"待写清单"（对应大纲外的增量），章末不得顺手展开——那是另一章的事。

## 3. 案例纪律

- 每个论点至少1个案例；**真实/改编/虚构必须标注**（改编写"根据真实情况改编"，虚构不得冒充真实）。
- 案例包含失败样本（只讲成功=幸存者偏差；至少一处"这样做失败过"）。
- 案例人物/公司匿名处理规则：具名须有来源许可，否则用"某X"。

## 4. 图表规范

- 每图/表有编号+标题+来源（无来源标"待确认"）。
- 图表必须在正文中被提及并解读（"如图X所示，关键在于……"），孤立图表=删除。
- 流程用流程图，对比用表格，趋势用曲线——图表类型与信息类型匹配。

## 5. 背景纪律

禁在前三章堆砌背景/理论/术语（读者最痛卡点在前三章直接开解）；背景知识按需分散到用到处的前一章或当章"边栏式"短注（≤150字）。

## 6. 每章交付前自检

①六段骨架齐全；②操作步骤可照做颗粒度；③案例≥1且有真实性标注；④图表有编号来源且被正文解读；⑤字数在单章区间；⑥章末钩子与下一章呼应。
