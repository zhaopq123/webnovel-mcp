# 模板 · toolbook 事实核查清单（每章交付门+完稿全量）

> 适用：工具书/非虚构赛道阶段4 ｜ 规则依据：toolbook-stage4-factcheck 切片
> 执法纪律：两遍交付制（写作遍+核查编辑遍）；任何一项不过关→修改→重检→循环至全通过才输出。禁止标注问题但照常交稿。

## 每章核查（六项逐条勾销）

| # | 核查项 | 结果 | 备注 |
|---|---|---|---|
| 1 | 数字一致性（同一事实全书同口径，对照台账） | □ |  |
| 2 | 引用可溯（来源在"已确认来源清单"内；否则标"待确认"交用户裁决） | □ |  |
| 3 | 案例真实性（真实/改编/虚构标注相符；匿名无指向泄露） | □ |  |
| 4 | 交叉引用核对（"如第X章所述"逐条回查，章号调序后高发） | □ |  |

| 6 | 立场区分（观点措辞 vs 给来源的事实陈述在位） | □ |  |

## 完稿全书级自检（顺序执行）

- [ ] ① 术语表全扫（一词一义）
- [ ] ② 数字全扫（口径表对照）
- [ ] ③ 交叉引用全扫
- [ ] ④ 章节承诺-定位声明对齐（每章功能回读定位声明，偏题章返工）
- [ ] ⑤ 重复内容检测（同概念两处展开=合并）
- [ ] ⑥ 依赖倒挂复查
- [ ] ⑦ "待确认"清零核销（已裁决移入来源清单；未裁决的汇总附交付说明）

## 修订优先级（降序执行，润色不得改事实）

事实错误（含来源失效）> 结构问题（依赖倒挂/重复/偏题）> 术语不一致 > 表达润色
