# 模板 · jubensha 线索卡

> 适用：剧本杀赛道阶段4四件套之一 ｜ 规则依据：剧本杀 v4.0 7.2（切片 jubensha-stage4-deliverables）
> 纪律：分幕阅读文本中引用的信件、字条，其线索卡内容必须与剧本内文逐字一致。

## 线索卡（单张格式）

```
┌─────────────────────────────┐
│ 线索编号：____（如 L-2-07）     │
│ 投放：第__幕 第__轮搜证        │
│ 所在场景：____                │
│ 可搜者：____                  │
│ 公开性：全桌可见 / 定向可隐瞒 / DM条件触发 │
│ 内容：____                    │
│ 指向：实证 / 误导 / 噪音 → 指向____ │
└─────────────────────────────┘
```

## 线索台账（汇总）

| 编号 | 投放幕-轮 | 所在场景 | 可搜者 | 公开性 | 内容 | 指向（实证/误导/噪音） | 已被谁搜到 | 是否已公开 |
|---|---|---|---|---|---|---|---|---|

## 设计纪律

- 定向线索是博弈核心：搜到者可公开可隐瞒，其信息去向同步更新信息线（2.1）
- 可搜者分配逻辑：定向线索优先给相关角色，但至少一条实证线索的搜索路径对全员开放
- 误导线索（红鲱鱼）：错误推理路径+真实解释入红鲱鱼表
- 噪音线索：控制比例，防淹没实证
