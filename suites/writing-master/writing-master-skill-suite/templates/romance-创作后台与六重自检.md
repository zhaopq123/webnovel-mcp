# 模板 · romance 创作后台与六重自检（写后必附）

> 适用：言情赛道每章循环 ｜ 规则依据：言情引擎 v8.1 第十一节（切片 romance-ledger-review）
> 执法纪律：任何一项不过关→修改→重检该项→循环至全通过→才输出。禁止标注问题但照常交稿。

## 一、创作后台（五块）

1. **伏笔清单**：本章新埋（编号+内容+计划引爆位置）｜ 待兑现（编号+距上次露出几章，超12章标红预警）｜ 本章部分兑现（兑现了什么+还剩什么）
2. **期待线状态**：感情主线当前阶段/本章推进幅度｜男主动心线泄底手段+最新拼图碎片｜隐情线泄露百分比｜事业线本章进展
3. **信息差变动**：女主本章新知道什么｜读者本章新知道什么｜排序是否仍为读者＞男主＞女主
4. **人物状态更新**：称呼变化｜亲密度变化及驱动事件｜时间线推进（日期/星期/季节/已过天数）
5. **下章钩子方向**：最近三次钩子类型记录+下章建议类型

## 二、六重自检（逐条打勾或说明修改点）

**写前自检**
- [ ] 推进了哪条期待线？达到三章一进展了吗？
- [ ] 钩子类型与上章重复了吗？
- [ ] 糖虐等级符合节拍表位置吗？
- [ ] 核心情绪是爽/疼/痒哪种？与上章交替了吗？

**写后自检A 结构与人物**
- [ ] 男主内心全程未直写（禁"他心想/他觉得/他暗自"）？
- [ ] 信息差排序保持？
- [ ] 女主有主动决定？钝感有度（同类暗示到第3次仍未起疑=违规）？
- [ ] 亲密度上升有事件驱动？
- [ ] 本章细节与档案卡、既往章节、时间线一致？伏笔已登记？

**写后自检B 去AI味+禁英文**
- [ ] 正文无任何英文字母/单词/缩写？
- [ ] 黑名单词汇逐词清查无命中？("微微/淡淡/缓缓/轻轻"每千字≤3)
- [ ] 无"不是A而是B"假靶子句/自问自答腔？情绪直告全部转身体反应？叠加式描写合并？超25字长句拆了？连续三句等长的段落改了？
- [ ] 每场景≥2种感官（含嗅觉/触觉/温度）？章末避开四种禁止收尾？无作者旁白点评？段落长短参差？

**写后自检C 对白**
- [ ] 遮住名字能认出谁在说话？每句台词在干活？
- [ ] 无客服式完整句/英文夹杂？有打断、抢话、"没用的东西"？
- [ ] 关键情感台词笨拙化？无华丽告白腔？有动作锚定？
- [ ] 无超5行连续裸引号？双方对白节奏有区隔？

**写后自检D 钩子与留存**
- [ ] 读者读完本章心里压着的未解问题能具体说出来？
- [ ] 给了"就差一点"而不是"吃饱了"？
- [ ] 本章张力比上章高？黄金三章内通过三章清单？

**写后自检E 余味**
- [ ] 至少一处用留白而非直告？
- [ ] 有"当时没在意回头看才懂"的细节？有则记入台账。

> 工具联动：自检全过后 → `bash scripts/wm-commit.sh`（提交摘要与台账增量）→ auto 模式直接写下一章；collab 模式向用户确认后继续。
